# NOCTRAIL｜南天星座イラスト 第1弾6星座 制作指示書

作成日：2026-11-02  
状態：**制作仕様の確定案／画像差し替えは未実施**

## 1. 現物比較とゴール

現行の高品質基準：`constellation-art/celestial-01-v11.json` の「オリオン座」。暗い青色の星空、天の川、遠景の地平線、立体感ある主役モチーフ、星座線と主な恒星の組み合わせ、左側の見出し・解説・情報パネル、下部の方位案内による統合された図鑑イラスト。

改修対象に見られる課題：`celestial-23-v18.json`（テーブルさん座・じょうぎ座）、`celestial-24-v18.json`（はちぶんぎ座・とけい座）、`celestial-25-v18.json`（ポンプ座）、`celestial-22-v18.json`（コンパス座）。現状は平坦な図形が主役となり、奥行き・素材・物語性が基準より低い。

目標：**星座モチーフ自体の歴史的正確性を維持したまま、オリオン座の画面構成・描画密度・発光感に品質を統一する。** 「星座線の模式図」と「象徴モチーフ」は明確に区別し、実際の恒星配置を勝手に創作して観測図と称さない。

## 2. 全6枚共通の画面仕様

- 16:9の横長画面、推奨1600×900 px（最低1280×720 px）、WebP。低容量化してもタイトル・恒星名の判読性を維持。
- 主役モチーフは画面右側約55〜60％、左約40〜45％に和文名称（大）、ラテン名（小）、2〜3行の解説、下段に観測情報のボックス。背景は深い群青〜青紫の星空、下端に遠景・薄明のグラデーション。
- オリオン座のような3D風の立体的質感。主役は単色の塗りつぶし・平面的な線画のみで済ませず、明部・陰影・素材・細部構造を描写。
- 色調：ディープネイビー #07162D、群青 #243A6A、スターライトブルー #9CCAFF、オフホワイト #E8F2FF、控えめな金色 #E0BD79。アクセントは各星座で1色だけ変更可。
- 背景星は不均一な明るさで自然に散らし、重要な星座線は主役を潰さない細い白青線で重ねる。恒星名と星の位置は信頼できる星図で照合してから掲載。
- 遠景は主役の視認性を下げない程度。装飾用の点光や星雲は天文観測対象と混同しないようにする。
- 日本語の誤字、英語・ラテン語表記、観測可否、実際のモチーフは納品前に別途校正。星の結線図は「模式図」と明記。
- **南半球の星座は「日本で絶対に見えない」と一括表記しない。** 見えるかは緯度・赤緯に依存し、東京基準の可視性と南西諸島を区別する。とくにテーブルさん座・はちぶんぎ座は日本から基本的に見えない。

## 3. 各星座の個別制作指示

### A1｜テーブルさん座（Mensa）｜最優先

**本来の題材：南アフリカ・ケープタウン近くのテーブルマウンテン。家具のテーブルではない。**

- 主役：水平で広い山頂稜線、切り立った岩壁、細やかな岩肌。山頂を横切る薄い「テーブルクロス状」の雲を配置。
- 構図：山体が右半分を大胆に占め、麓には奥行きある海岸と夜空。銀河・星の光が山頂に淡く反射。
- 色彩：藍色の岩、霞んだ青紫、白銀の雲。稜線と岩の陰影は立体的に。
- 重要度：山の固有形状を一見して判別できること。建物・天文台・家具は主役にしない。
- 見出し：「テーブルさん座 / MENSA」。説明案：「南アフリカのテーブルマウンテンに由来する南天の星座。」観測欄は「日本（東京）からは見えない」を優先。
- **避ける**：机、三角形の山だけの図、木のテーブル、山頂が尖った火山型。

### A2｜はちぶんぎ座（Octans）

**本来の題材：八分儀。緯度や天体高度の測定に使われた歴史的な角度測定器。**

- 主役：およそ45°の弧と目盛り、視準器、鏡・金属アームなどを持つ実在感ある真鍮製の八分儀。
- 構図：右側中央の斜め三四分構図。弧の外周の刻印、ねじ、関節、磨かれた金属の反射で描写密度を確保。背後に南天の極周辺を示唆する星空。
- 色彩：鈍い金色、青銀、静かな青白色の反射。科学機器としての精密さを主役に。
- 見出し：「はちぶんぎ座 / OCTANS」。説明案：「南天の極付近にある、八分儀に由来する星座。」観測欄は「日本（東京）からは見えない」。
- **避ける**：丸時計、単純な円盤、六分儀との安易な混同、矛盾する目盛り構造。

### A3｜ポンプ座（Antlia）

**本来の題材：18世紀の空気ポンプ・真空実験装置（Antlia Pneumatica）。**

- 主役：木製の実験台、真鍮のバルブ・管、ガラスの容器または真空ベル、手動ポンプの機構を備えた古典科学器具。
- 構図：右中央に斜め前方から俯瞰気味に見せる。透明ガラスの反射、管のつながり、ピストン・レバーの質感が分かる。
- 色彩：透明な淡青ガラス、銅金、深藍の木製・金属質感。光の粒は背景装飾に留める。
- 見出し：「ポンプ座 / ANTLIA」。説明案：「空気を抜く科学実験用のポンプに由来する星座。」見える条件については、観測地の緯度を踏まえて別途校正。
- **避ける**：歯車だけ、現代の水道用ポンプ、単色の抽象図形、科学的根拠なく星を吸い込む構造。

### A4｜じょうぎ座（Norma）

**本来の題材：大工や製図で使う直角定規・差し金、直角を測る道具。**

- 主役：直角を成す二辺、刻み目、面取りされた金属・木材、精密な角材の材質を見せる古典的な直角定規。
- 構図：右中央に少し傾けて配置。光を受ける直角の外縁と薄い陰影で奥行きを表現。細い補助線は主役より薄く。
- 色彩：青銀とアンティークゴールド、青紫の影。直角定規が主役であることを失わない。
- 見出し：「じょうぎ座 / NORMA」。説明案：「直角を測る定規に由来する南天の星座。」可視性表示は観測地点の基準を明示。
- **避ける**：長い一本の直線定規だけ、分度器だけ、無関係な魔法陣。

### A5｜コンパス座（Circinus）

**本来の題材：製図用のコンパス。方位磁針や羅針盤（Pyxis）ではない。**

- 主役：二本脚、開閉支点、片側の鋭い針ともう片側の鉛筆・描画先端、精密なヒンジを持つ金属製ディバイダー／製図コンパス。
- 構図：脚の開きでV字の流れを生み、右中央に大きく配置。薄く刻まれた円弧を背景に添え、描画作業の動きを感じさせる。
- 色彩：鏡面シルバー、真鍮の接合部、青緑の小さな反射。
- 見出し：「コンパス座 / CIRCINUS」。説明案：「円や弧を描く製図用コンパスに由来する南天の星座。」
- **避ける**：N/S/E/W付きの方位磁針、羅針盤、コンパス針の磁場表現。

### A6｜とけい座（Horologium）

**本来の題材：振り子時計（pendulum clock）。**

- 主役：木と真鍮の古典的な振り子時計。文字盤、長い振り子、ゼンマイ・歯車・針を一体の器具として自然に描く。
- 構図：右側に縦長時計を少し斜め向きに置き、画面の奥に薄い星雲と夜の静けさ。振り子の振幅を微かな残光で示してもよい。
- 色彩：深い青木目、真鍮・薄金、時計盤の白い反射。ほか5枚より金色をやや多めに。
- 見出し：「とけい座 / HOROLOGIUM」。説明案：「振り子時計に由来する南天の星座。」
- **避ける**：腕時計、デジタル時計、架空の時計だけで振り子が存在しない描写。

## 4. 共通画像生成用のベース指示

「NOCTRAILという日本語の星座図鑑アプリで使用する、16:9横長の高品質な星座解説アート。すでに存在するオリオン座のイラストと同等の構図と細密さを持たせる。深い群青の天体写真風背景、星雲・銀河・自然な星光、遠景の山並み、写真のような立体感を持つ歴史的・象徴的モチーフ、白青に発光する主な星と控えめな星座線。画面左側には見出しと説明・観測情報のための読みやすい余白を設け、右側に物体・風景を十分大きく描く。主役のモチーフは[個別星座名]の史実に忠実。単色の単純な輪郭や記号的な塗りつぶしにしない。科学的に誤認しやすい装飾、誤った星座名、文字崩れを避ける。」

実際に生成する際はこのベース指示にA1〜A6の個別指示を追加する。**可能なら主題イラストと文字・星座線を分けて編集・合成し、文字の誤植と星の位置誤りを防止する。**

## 5. 実装・検品

- 現在のページでは `customConstellationManifest` が各星座名をJSONアセットへ対応付けている。
- 現行コードは `data:image/webp;base64,` での表示を想定している。生成画像をWebPにエンコードし、各星座をキーとするbase64文字列としてパックへ格納する。
- 既存のJSONパックには変更対象外の星座も同居しているため、**キーを誤って上書きしないこと**。必要なら新規の2パック（3枚ずつ）を用意し、対象6星座のマニフェストだけ変更。
- 既存アセットに依存するほかの星座、訪問記録、星空／夜景写真は絶対に変更しない。
- 描画テスト：6星座すべてで①初回読込、②画像拡大表示、③スマートフォン縦持ち、④タブ切替後の再表示、⑤表示失敗時のフォールバックを確認。
- 見た目：オリオン座と横並び比較して、主役の立体感／背景密度／タイトル／観測情報／色調／情報量が同等であること。
- 校正：天文学用語、星座ラテン名、東京と沖縄など緯度による可視性、掲載する恒星名と星座線を別途確認。
- 品質合格まで旧画像を残し、6枚まとめて切替できるようにする。

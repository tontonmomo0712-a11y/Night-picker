# NOCTRAIL｜南天星座6作品の差し替え・配信手順

更新日：2026-11-02

## 現在の状態

- 対象：テーブルさん座、はちぶんぎ座、ポンプ座、じょうぎ座、コンパス座、とけい座。
- 完成案：各960×540px WebP、天体図鑑向け高密度のビジュアル。
- 配信用JSON：`celestial-28-v20.json`（テーブルさん座、はちぶんぎ座、ポンプ座）、`celestial-29-v20.json`（じょうぎ座、コンパス座、とけい座）。
- NOCTRAILの`index.html`に「新パックを試し、取得に失敗した場合は従来パックに戻る」安全な読み込み処理を実装済み。
- **画像パックはまだGitHubリポジトリに未登録。** 追加されるまでは従来の星座絵が表示される。

## 配信開始までの残作業

1. 6枚のWebPおよび新パック2個をダウンロード・レビューする。
2. GitHubのリポジトリで `constellation-art/` を開き、`Add file` → `Upload files` を選択する。
3. 新パック **`celestial-28-v20.json` と `celestial-29-v20.json` の2ファイルだけ** をアップロードして `Commit changes` する（WebPは素材兼バックアップ、サイトの読み込みに直接は使用しない）。
4. NOCTRAIL公開サイトを再読み込みし、6星座それぞれを選択して表示する。星座絵の拡大も確認する。
5. EdgeOneで最新の `index.html` が配信されていなければ、デプロイ設定・同期を確認する。

**重要：** 現在の接続からは、画像ファイルを生成コンテナからGitHubに直接コピーできないため、手順3は未実施。アップロード前に公開済みとして案内しない。

## 品質と天文学的記述に関する注意

- ベースの生成画像には誤記の可能性があるため、文字や観測可否の表示を外して、象徴モチーフを主体としたWebPへ切り出した。
- テーブルさん座は南アフリカのテーブルマウンテン、コンパス座は製図用コンパス。観測地点により南天星座の見え方が異なる。
- 生成画像の星座線や星の位置は装飾的・模式的なもので、実際の恒星位置とは照合していない。
- 目指すオリオン座相当のクオリティに達しているか、表示と比較して最終校正が必要。
